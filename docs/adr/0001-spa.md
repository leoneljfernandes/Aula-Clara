# ADR-0001: Arquitectura de renderizado del frontend

- **Fecha:** 2026-11-17
- **Estado:** aceptada

## Contexto

Aula Clara es una herramienta personal de estudio: la usa cada estudiante sobre su propio material, con su perfil de lectura guardado en el navegador. No hay páginas públicas que necesiten indexarse ni vistas previas para redes sociales. La restricción principal es el **costo cero**, y el sitio tiene que poder publicarse también en GitHub Pages, que solo sirve archivos estáticos.

## Decisión

**SPA** con Vite + React 19 + React Router v8 en *data mode* (loaders, actions, rutas lazy). Se publica como archivos estáticos en Vercel (junto a la función de FastAPI) o en GitHub Pages.

## Alternativas descartadas

- **Pre-render (React Router framework mode con `ssr: false`)**: no hay rutas públicas cuyo contenido se conozca en el build. Sumaría complejidad sin beneficio.
- **SSR (React Router framework mode o Next.js)**: requiere un runtime de Node en producción. No funciona en GitHub Pages y no resuelve ningún requisito del producto (SEO, LCP de contenido público).

## Costo aceptado

La primera carga muestra el shell antes de los datos. Se mitiga con rutas lazy (un chunk por vista; pdf.js y mammoth fuera del bundle inicial) y con `HydrateFallback` donde haga falta.

## Criterio de revisión

Reabrir esta decisión si aparece contenido público que deba indexarse (por ejemplo, un catálogo de material abierto), o si el LCP p75 en mobile supera 2,5 s por culpa del JavaScript y no del backend.
